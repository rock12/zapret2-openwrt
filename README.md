[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg?style=flat-square)](https://opensource.org/licenses/MIT)

**zapret2-openwrt** — универсальный автономный программный комплекс для роутеров OpenWrt, объединяющий глубокий обход блокировок **DPI (Zapret2 / nfqws2)**, низкопинговый туннель **Cloudflare WARP на базе AmneziaWG (AWG 2.0 / 3.1)** с обфускацией, прозрачный туннель **Telegram** и интуитивный веб-интерфейс **LuCI** с раздельными тумблерами для популярных онлайн-игр.

---

## ⚡ Ключевые возможности

### 🔄 1. Обход DPI нового поколения (Zapret2 / nfqws2 + z2k Architecture)
- Полноценная 8-профильная архитектура `nfqws2` со специализированными профилями под каждый тип трафика:
  - **YouTube TCP** (ротация стратегий fake, multisplit, fake-disorder, tls_client_hello_clone)
  - **Googlevideo CDN (GV)** (отдельная независимая лестница стратегий для максимальной скорости 4K 60fps)
  - **RKN TCP** (обход блокировок веб-ресурсов, Twitter/X, Instagram, трекеров)
  - **QUIC / HTTP3 (UDP 443)** (мульти-стратегии с фейковыми заголовками и фрагментацией)
  - **Discord Voice & Calls (UDP)** (пропуск голосовых шлюзов и STUN)
  - **HTTP (TCP 80)** (методы eol, syndata, split)
  - **WhatsApp** (шумоподавление и стабилизация)
  - **Автоматический детектор аномалий (autohostlist)** с авторотацией
- **FastPath Auto-Exclude:** Незаблокированные ресурсы идут напрямую через вашего провайдера на максимальной гигабитной скорости без очередей `NFQUEUE` и нагрузки на процессор роутера.

### 🤖 2. Автоподбор стратегий (z2k Native Circular Auto-Tuning & Persistence)
- **Нативная ротация `circular` в `nfqws2`:** больше не нужно вручную подбирать параметры `--lua-desync` под своего провайдера!
- **Автоматическое переключение на лету:**
  - Если провайдер или ТСПУ блокируют текущую стратегию (детектируются повторные SYN/ACK retransmissions, таймауты или сбросы соединения), `nfqws2` автоматически переключает домен на следующую стратегию из лестницы (`circular:fails=3:time=60`).
  - Система тестирует проверенные desync-атаки (`multisplit`, `hostfakesplit`, `fake`, `fakeddisorder`, `fakedsplit`, различные сдвиги `pos`, `seqovl` и фейковые SNI-пейлоады).
- **Энергонезависимая память стратегий (`state.tsv`):**
  - Модуль `z2k-state-persist.lua` сохраняет успешно подобранную стратегию для каждого домена в кэш `/opt/zapret2/extra_strats/cache/autocircular/state.tsv`.
  - При перезагрузке роутера или службы роутер мгновенно загружает сохраненные рабочие стратегии без повторного ожидания перебора!

### 🎮 3. Игровой туннель Cloudflare WARP на базе AmneziaWG
- Полноценная поддержка протокола **AmneziaWG** с защитой от блокировок WireGuard со стороны ТСПУ в РФ (`Jc`, `Jmin`, `Jmax`, `H1-H4`, `I1`).
- **📱 Маршрутизация устройств через WARP (Device Routing):**
  - Возможность направить **всё интернет-соединение** выбранных устройств (игровые консоли PS5 / Xbox, ПК, Smart TV, смартфоны) через WARP-туннель по IP или MAC-адресу.
  - **Защита локальной сети:** доступ к устройствам домашней сети и веб-интерфейсу роутера сохраняется напрямую без потерь.
- **🛡️ Чистые списки игр из [YOZH3G/ru-gaming-blocklist](https://github.com/YOZH3G/ru-gaming-blocklist):**
  - Встроенный санитайзер `warp-list-filter.awk` исключает частные подсети, провайдеров, хостинги (Hetzner, AWS) и мусорные диапазоны — ваш обычный интернет никогда не пойдет в WARP!
- **Персональные тумблеры (ВКЛ / ВЫКЛ)** прямо в веб-интерфейсе для каждой игры:
  - 🔘 **Community Curated Gaming IP Pool** (отборный игровой пул сообщества)
  - 🔘 **Call of Duty: Warzone & Modern Warfare** (серверные подсети)
  - 🔘 **Battlefield 6 / 2042 (EA DICE)**
  - 🔘 **Steam** (голосовые чаты и игровые серверы без лишнего трафика загрузок)
  - 🔘 **EA App / Origin**
  - 🔘 **Battle.net / Blizzard**
  - 🔘 **Epic Games & Fortnite**
  - 🔘 **Riot Games & Valorant**
  - 🔘 **Apex Legends & Rocket League**
  - 🔘 **Ubisoft / Rainbow Six Siege**
  - 🔘 **Roblox**
  - 🔘 **League of Legends**
  - 🔘 **Warframe**
  - 🔘 **Dead By Daylight**, **Arma Reforger**, **Minecraft** и др.
- Кнопка **`[ View / Edit ]`** позволяет в браузере просматривать или добавлять свои игровые подсети и IP-адреса.

### 🎯 4. WARP Scout (Автоподбор минимального игрового пинга)
- Роутер самостоятельно опрашивает десятки серверов Cloudflare с вашей интернет-линии и выбирает эндпоинт с **минимальным пингом** (от 20 мс) и нулевой потерей пакетов.

### ✈️ 5. Прозрачный туннель Telegram (из z2k)
- Автономный клиент `tg-mtproxy-client` (WebSocket TLS на порту `:1443`).
- Автоматически и прозрачно перенаправляет трафик Telegram через nftables: **мессенджер работает на всех смартфонах, ПК и Smart TV в домашней сети без необходимости включать прокси на самих устройствах**.
- Полностью независим от WARP (не забивает игровой туннель) и не конфликтует с внешними клиентами (Happ, Xray, Sing-Box, Shadowrocket, V2Ray).

### 🔒 6. Оптимизация DNS (dnsmasq Anti-Leak)
- Фильтрация IPv6 AAAA-записей (`filter_aaaa=1`), предотвращающая утечки трафика мимо IPv4 десинхронизатора `nfqws2`.
- Встроенный фикс IP-блокировок Instagram/Meta (`31.13.72.36`).
- Надежная работа со стандартным DNS вашего провайдера или сторонними серверами без риска падения сети.

## 💾 Сколько места и ресурсов занимает

Комплекс спроектирован для максимальной экономии ресурсов роутера:

| Компонент | Память Flash (ROM) | ОЗУ (RAM) | Нагрузка на CPU |
|---|---|---|---|
| **Ядро Zapret2** (`nfqws2`, lua, списки хостов) | ~2.2 МБ | ~8–12 МБ | < 1% (FastPath разгрузка) |
| **AmneziaWG** (модуль ядра `kmod-amneziawg` + утилиты) | ~0.15 МБ | ~1–2 МБ | 0% (работает в ядре Linux) |
| **Веб-интерфейс LuCI** (`luci-app-zapret2`) | ~0.12 МБ | 0 МБ (статика) | 0% |
| **Telegram WebSocket Client** (`tg-mtproxy-client`) | ~5.6 МБ | ~8–12 МБ | < 0.5% |
| **ИТОГО (весь комплекс "под ключ")** | **~8.1 МБ** | **~18–26 МБ** | **< 1.5%** |

> [!TIP]
> Комплекс отлично работает даже на бюджетных роутерах с **128 МБ RAM** и **32 МБ Flash**.

## 🚀 Быстрая установка (в 1 команду)

Подключитесь к роутеру по SSH (`ssh root@192.168.1.1`) и выполните команду:

```sh
curl -sSL https://raw.githubusercontent.com/rock12/zapret2-openwrt/zap1/install.sh | sh
```

*(Если утилита `curl` не установлена, выполните через `wget`:)*
```sh
wget -qO- https://raw.githubusercontent.com/rock12/zapret2-openwrt/zap1/install.sh | sh
```

### Системные зависимости (устанавливаются автоматически)
Скрипт проверяет и автоматически ставит все необходимые пакеты для вашего пакетного менеджера (`apk` или `opkg`):
- `curl`, `ca-bundle`, `ca-certificates` — для защищённой загрузки списков и конфигураций.
- `nftables`, `kmod-nft-core`, `kmod-nft-nat`, `kmod-nft-queue`, `kmod-nf-conntrack` — ядро фильтрации трафика и очереди NFQUEUE для `nfqws2`.
- `ip-full` — для расширенных политик маршрутизации (PBR, fwmark, отдельные таблицы).
- `bind-tools` — утилиты проверки доменов и DNS-резолвинга.
- `dos2unix` — устранение несовместимых переводов строк Windows CRLF.
- `https-dns-proxy`, `luci-app-https-dns-proxy` — зашифрованный DoH (DNS-over-HTTPS) для защиты от подмены DNS провайдером.
- `kmod-amneziawg`, `amneziawg-tools` — модуль ядра и тулзы AmneziaWG (если их нет в стандартных репозиториях OpenWrt, скрипт автоматически ставит их из репозитория Slava-Shchipunov).

### 📋 Что делает скрипт установки (Пошаговый разбор `install.sh`)

Инсталлятор полностью автономен, выполняет развёртывание "под ключ" и оптимизирован под любые архитектуры:

1. **[1/7] Проверка системы и архитектуры**:
   - Проверяет права root;
   - Определяет пакетный менеджер роутера (`apk` для OpenWrt >= 25.12+ или `opkg` для OpenWrt <= 24.10);
   - Определяет аппаратную архитектуру ЦПУ (`aarch64`, `x86_64`, `arm`, `mips`).

2. **[2/7] Установка системных зависимостей**:
   - Обновляет репозитории пакетов;
   - Ставит ядро фаервола `nftables`, модули очередей `NFQUEUE`, утилиты сети `ip-full`, `bind-tools`, конвертер строк `dos2unix`;
   - Ставит и сохраняет сервис безопасного DNS **`https-dns-proxy`** (DoH);
   - Устанавливает модуль ядра **AmneziaWG** и бинарные пакеты `zapret2` (`nfqws2`) и веб-интерфейса `luci-app-zapret2`.

3. **[3/7] Настройка каталогов и компонентов**:
   - Создаёт рабочие каталоги `/opt/zapret2`, `/opt/zapret2/warp`, `/opt/zapret2/ipset`;
   - Распаковывает Lua-модули `z2k` (ротация, детекция, персистентность состояния `state.tsv`);
   - Копирует наборы фейковых бинарных блобов (TLS ClientHello, QUIC, STUN);
   - Копирует санированные списки игровых подсетей;
   - Копирует скрипт деинсталляции в `/opt/zapret2/uninstall.sh`.

4. **[4/7] Защита от CRLF и установка прав**:
   - Автоматически конвертирует все скрипты, конфиги и списки в чистый UNIX `LF` через `dos2unix` и `tr`;
   - Выставляет права на исполнение (`chmod +x`).

5. **[5/7] Прозрачный туннель Telegram (`tg-tunnel`)**:
   - Скачивает клиент `tg-mtproxy-client` под архитектуру процессора;
   - Настраивает независимую службу на порту `:1443` с изолированной таблицей `tg_tunnel` в `nftables` (без конфликтов с `fw4`).

6. **[6/7] Полное отключение IPv6 (Anti-Leak)**:
   - Отключает DHCPv6 и Router Advertisement на LAN (`dhcp.lan.dhcpv6=disabled`, `dhcp.lan.ra=disabled`);
   - Включает фильтрацию IPv6 AAAA-записей в `dnsmasq` (`filter_aaaa=1`), чтобы клиенты всегда шли по защищённому IPv4;
   - Отключает DHCPv6-клиент на внешнем порту `wan6`;
   - Безопасно отключает IPv6 на `wan` и `br-lan` через `/etc/sysctl.d/99-disable-ipv6.conf` (сохраняя локальный loopback `lo` для работоспособности внутренних служб);
   - Прописывает устойчивые DNS-пины для Instagram и Discord (`discord.media`).

7. **[7/7] Интеллектуальная настройка MTU и TCP MSS Clamping**:
   - Включает `mtu_fix='1'` в файрволе для автоматического согласования MSS;
   - **Автоматически распознаёт топологию сети**:
     * **Каскад из 2 роутеров** (OpenWrt за провайдерским роутером/GPON ONT в приватной подсети `192.168.*`, `10.*`, `172.16-31.*`) — автоматически выставляет безопасный **MTU 1480** на WAN, исключая фрагментацию пакетов, дропы десинка `nfqws2` и эффект "Path MTU Black Hole" в Double NAT;
     * **Прямое подключение (1 роутер)** — выставляет стандартный MTU 1492 для PPPoE или MTU 1500 для DHCP/Static.

8. **Настройка конфигурации Zapret2 (UCI)**:
   - Настраивает порты TCP `80,443,2053,2083,2087,2096,8443`;
   - Настраивает полный диапазон UDP-портов Discord: `1400,3478-3481,5349,19294-19344,50000-65535`;
   - Включает лестницу стратегий: YouTube, Googlevideo CDN, скоростной `fake_badseq_multisplit` для Cloudflare/РКН с отечественной приманкой `vk.com`;
   - Включает приманку `quic_dbankcloud` для голосового протокола Discord;
   - Активирует автообучение новым доменам (`hostlist-auto`) с непрерывным фоновым демоном `autolearn-cidr.sh`;
   - Блокирует QUIC (UDP 443) в файрволе для мгновенного перехода браузеров на быстрый десинк TCP.

9. **Запуск и автозагрузка служб**:
   - Включает в автозагрузку и перезапускает `zapret2`, `tg-tunnel`, `https-dns-proxy`, `dnsmasq`, `firewall`, `uhttpd` и `rpcd`.

## 🖥️ Как пользоваться и менять стратегии в LuCI

### 1. Доступ к веб-интерфейсу
1. В браузере перейдите по адресу: **`http://192.168.1.1`**
2. В верхнем меню откройте: **Службы** → **Zapret 2**

### 2. Вкладка «Cloudflare WARP (Games)»
- **Enable Cloudflare WARP Tunnel** — мастер-тумблер игрового туннеля (по умолчанию включён).
- **Scout Endpoint** — кнопка сканирования серверов Cloudflare для выбора эндпоинта с минимальной задержкой.
- **📱 Устройства через WARP (Device Routing)** — удобный ввод IP или MAC-адресов домашних устройств (консоли, ПК, ТВ) с кнопкой **«Edit devices.txt»**.
- **🎮 Игровые тумблеры** — включайте и отключайте маршрутизацию для каждой конкретной игры в 1 клик с возможностью просмотра и добавления подсетей по кнопке **«View / Edit»**.

### 3. Вкладка «Telegram (z2k Tunnel)»
- Прозрачный высокоскоростной WebSocket-туннель для Telegram на базе MTProxy client (порт `:1443`).
- Работает полностью автономно и независимо от WARP, обеспечивая мгновенную доставку сообщений и медиа на всех устройствах.

### 4. Как правильно менять стратегию в LuCI (Важно!)
Поле со стратегией `NFQWS2_OPT` в веб-интерфейсе сделано **только для чтения** (`readonly`), чтобы длинные параметры не нарушали верстку:
1. Нажмите кнопку **«Редактировать» (Edit)** рядом со строкой `NFQWS2_OPT`.
2. В открывшемся всплывающем окне внесите или вставьте нужную стратегию.
3. **Обязательно нажмите кнопку «Сохранить» (Save)** *внутри этого окна*.
4. Окно закроется, а новая стратегия отобразится в поле.
5. Нажмите синюю кнопку **«Сохранить и применить» (Save & Apply)** в самом низу страницы LuCI.
> [!NOTE]
> Скрипт службы `zapret2` автоматически синхронизирует изменения в файл демона `/opt/zapret2/config` и перезапускает `nfqws2` на лету.

В комплексе реализована полноценная разблокировка всех компонентов Discord, включая голосовые каналы:
1. **Голосовые порты и медиа-потоки (UDP)**:

   - `50000-65535` — динамический WebRTC RTP пул голосовых серверов Discord.

   - Все поддомены `*.discord.media` (например, `finland*.discord.media`, `rotterdam*.discord.media`) через `dnsmasq` привязаны к Cloudflare IP `104.25.158.178`. Это полностью предотвращает зависание клиента на статусе *«Connecting» / «Подключение к RTC...»*.

## 🌐 RuTracker & Cloudflare: Устранение зависания на 10-12 КБ

Ранее при загрузке сайтов под защитой Cloudflare (`discord.com`, `rutracker.org`, `nnmclub.to`) соединение зависало после первых 10-12 КБ из-за того, что 7-сегментный `multidisorder` триггерил анти-DDoS фильтры Cloudflare.
- **Решение**: Применена стратегия **`fake_badseq_multisplit`**:
  ```text
  --lua-desync=fake:blob=stun_fake:repeats=6:tcp_seq=1000:tcp_ack=-66000 --lua-desync=fake:blob=tls_google:repeats=6:tcp_seq=1000:tcp_ack=-66000 --lua-desync=multisplit
  ```
- **Результат**: Фейки с фиктивными `tcp_seq` и `tcp_ack` обманывают ТСПУ, а серверы Cloudflare корректно отбрасывают их и отдают трафик на полной скорости без зависаний (тесты: RuTracker и Discord отдают HTTP 200 за < 0.5 с).

## 🧠 Автоподбор стратегий и автообучение новым сайтам

Система поддерживает два уровня автоматизации:

### 1. Автообучение новым доменам (`hostlist-auto` + `autolearn-cidr.sh`)
- Если вы или ваше приложение открываете новый заблокированный ресурс, которого ещё нет в списках:
  1. Демон `nfqws2` фиксирует 3 сбоя соединения в течение 60 секунд (`--hostlist-auto-fail-threshold=3`).
  2. Домен автоматически записывается в `/opt/zapret2/ipset/zapret-hosts-auto.txt` и лог `/opt/zapret2/ipset/zapret-hosts-auto-debug.log`.
  3. Фоновый демон `autolearn-cidr.sh` (PID в `/tmp/zapret2_autolearn.lock`) моментально резолвит домен, агрегирует подсеть CDN (`/24`) и добавляет её в `nftables set zapret`.
  4. Последующие запросы к ресурсу идут через десинк автоматически.
- **Мониторинг логов**: `tail -f /tmp/zapret2_autolearn.log`.

### 2. Экспресс-подбор рабочей стратегии под домен (`quick-tune.sh`)
Если вам нужно мгновенно подобрать стратегию под проблемный ресурс:
```sh
/opt/zapret2/quick-tune.sh <домен>
```
Скрипт поочередно тестирует стек стратегий и выводит готовую команду с кодом `SUCCESS`.

### 3. Встроенные тесты диагностики (`dwc.sh`)
- **Проверка сайтов** (YouTube, Discord, RuTracker, Instagram, Госуслуги и др.):
  ```sh
  /opt/zapret2/dwc.sh -s
  ```
- **Проверка DPI по TCP 16-20** (мировые CDN: Cloudflare, Akamai, AWS, Hetzner, Fastly):
  ```sh
  /opt/zapret2/dwc.sh
  ```

## 📂 Куда добавлять свои домены и IP-адреса (IPCIDR)

В комплексе предусмотрены раздельные списки для пользовательских доменов, подсетей и исключений:

### 1. Добавление своих доменов (User Hostlist)
* **Через веб-интерфейс LuCI**:
  1. Перейдите в **Службы** → **Zapret 2** → вкладка **«Списки» (Lists)**.
  2. Найдите блок **«Пользовательский список доменов»** и нажмите кнопку **«Редактировать» (Edit)**.
  3. Внесите домены и сохраните.
* **Через консоль / SSH**:
  * Файл: **`/opt/zapret2/ipset/zapret-hosts-user.txt`**
  * Формат: по одному домену на строку, без `https://` и слэшей.
  * *Все поддомены охватываются автоматически!* Например:
    ```text
    notion.so
    custom-tracker.org
    my-blocked-service.com
    ```
* **Домены-исключения (белый список)**:
  * Файл: **`/opt/zapret2/ipset/zapret-hosts-user-exclude.txt`**
  * Домены из этого списка никогда не искажаются десинком (национальные зоны `.ru`, `.su`, `.рф`, банки и Госуслуги уже защищены встроенным фильтром).

### 2. Добавление своих IP-адресов и подсетей (IP / CIDR)
* **Через веб-интерфейс LuCI**:
  * Вкладка **«Списки» (Lists)** → блок **«Пользовательский список IP»**.
* **Через консоль / SSH**:
  * Файл: **`/opt/zapret2/ipset/zapret-ip-user.txt`**
  * Формат: одиночные IP (`1.2.3.4`) или подсети с маской (`1.2.3.0/24`):
    ```text
    104.21.32.0/24
    162.159.137.232
    ```
  * *Все адреса из этого файла автоматически подгружаются в `nftables` (набор `zapret`) и направляются в очередь десинхронизатора.*
* **IP-исключения (прямой трафик мимо Zapret)**:
  * Файл: **`/opt/zapret2/ipset/zapret-ip-exclude.txt`**

> [!TIP]
> После ручного редактирования файлов в терминале примените изменения одной быстрой командой без перезагрузки роутера:
> ```sh
> /etc/init.d/zapret2 reload
> ```

## 🗑️ Полное удаление комплекса

Если вам потребуется удалить комплекс, достаточно выполнить одну команду:

```sh
curl -sSL https://raw.githubusercontent.com/rock12/zapret2-openwrt/zap1/uninstall.sh | sh
```

Либо запустить локальный скрипт на роутере:
```sh
/opt/zapret2/uninstall.sh
```

### Что делает скрипт удаления:
- Полностью останавливает и отключает службы `zapret2`, `warp`, `tg-tunnel`, `tg-ws-proxy`, `https-dns-proxy`.
- Удаляет все правила `nftables`, таблицы `zapret`/`warp`/`tg_tunnel` и правила PBR (`fwmark`, таблица 100).
- Удаляет каталог `/opt/zapret2`, файлы веб-интерфейса LuCI, init-скрипты и бинарники.
- Восстанавливает оригинальные настройки DNS в `dnsmasq` и сбрасывает конфигурацию UCI.
- Перезапускает веб-сервер роутера. Роутер возвращается в исходное состояние "из коробки" без перезагрузки.
